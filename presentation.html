Syed Fazeel Ahmed — AI Architect

Multimodal AI Pipeline

Instead of humans manually reading, sorting, and verifying reports, our pipeline ingests raw unstructured field data and transforms it into structured, actionable municipal intelligence.

Gemini Vision LLM

  • Analyzes photo evidence semantically
  • Auto-classifies: Garbage / Pothole / Sewerage
  • Assigns severity: Low → Critical
  • Generates step-by-step field crew action plan

Whisper Speech-to-Text

  • Citizens speak in Urdu or Sindhi — no typing
  • Transcribes local dialect audio in real time
  • Translates into standardized municipal records
  • Extracts key entities (location, urgency, type)

Production-Grade Backend

  • FastAPI — async-first Python framework with automatic OpenAPI docs
  • SQLAlchemy ORM with SQLite Write-Ahead Logging for concurrent writes
